# 📊 Task 5: Sales Performance Capstone Dashboard

## 📌 Project Overview
This project focuses on analyzing a sales dataset to extract meaningful business insights and visualize key performance metrics through a dashboard.

The goal is to transform raw data into actionable insights that support data-driven decision-making.

---

## 🎯 Objectives
- Analyze overall sales performance
- Identify top-performing categories, products, and cities
- Understand customer purchasing behavior
- Detect monthly sales trends
- Build a visual dashboard for easy interpretation

---

## 🛠️ Tools & Technologies Used
- Python (Pandas, NumPy)
- Data Visualization (Matplotlib)
- Excel

---

## 📊 Key Insights
- Total Revenue: 139.4 Million
- Best Performing Category: Electronics
- Top Cities: Patna, Kolkata, Bengaluru
- Highest Revenue Month: March
- Lowest Revenue Month: September
- Age Group 36–45 contributes the most to revenue

---

## 📈 Dashboard
The dashboard provides a visual summary of:
- Revenue by Category
- Monthly Sales Trend
- Top 5 Cities by Revenue
- Revenue Distribution by Age Group
